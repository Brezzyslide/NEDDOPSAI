# NeedsOps AI+ Scripts

Utility scripts for database, deployment, and local development.

## Scripts

| Script | Description |
|---|---|
| `db-push.sh` | Push Drizzle schema to the development database |
| `seed.sh` | Seed development database with sample data |

## Usage

```bash
chmod +x infrastructure/scripts/*.sh

# Push schema
./infrastructure/scripts/db-push.sh

# Seed data
./infrastructure/scripts/seed.sh
```
