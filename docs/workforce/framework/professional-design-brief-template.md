# Professional Design Brief — Template

> **Purpose:** This document is the founder-approved design foundation for a NeedsOps AI Employee.  
> It is completed before any Employee File is written.  
> It is never sent to the Execution Runtime.  
> It is never used as prompt content.  
> It is the intellectual source from which the Employee File is derived.

---

> **Instructions for completing this Brief:**  
> Every section must be answered from direct professional experience, industry knowledge, or deliberate design decision.  
> Do not generate placeholder content.  
> Do not import from generic management frameworks.  
> If a section cannot be completed, leave it blank and note the reason — it is better to document a gap than to invent an answer.  
> This Brief must be reviewed and signed off before the Employee File is authored.
