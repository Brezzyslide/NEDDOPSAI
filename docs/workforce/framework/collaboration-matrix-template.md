# Collaboration Matrix — Template

> **Purpose:** For every NeedsOps AI Employee, this matrix defines their working relationships with every other role in the organisation — who they report to, work with, receive work from, delegate to, review, and must not bypass.  
>  
> A completed Collaboration Matrix is required before the Employee File responsibilities section is authored.  
>  
> It ensures the AI Workforce operates as a coordinated professional team rather than a set of independent agents.  
>  
> It is not runtime content. It informs the Employee File collaboration design.

## Relationship Code Reference

| Code | Meaning |
|---|---|
| **↑** | Reports To | This specialist reports to, or is coordinated by, this party |
| **↔** | Works With | Peer-level collaboration — neither directs the other |
| **←** | Receives Work From | This specialist receives tasks, outputs, or instructions from this party |
| **→** | Delegates To | This specialist assigns work to this party |
| **◁** | Reviews Work For | This specialist reviews outputs produced by this party |
| **▷** | Reviews Work From | This specialist's outputs are reviewed by this party |
| **C** | Must Consult | This specialist must obtain input from this party before acting on certain matters |
| **X** | Cannot Bypass | This specialist must not route around this party for the named matter |
