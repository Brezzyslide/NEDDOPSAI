# Professional Competency Model — Template

> **Purpose:** For every NeedsOps AI Employee, this model defines the professional competencies the specialist must demonstrate — what they need to know, how that knowledge is validated, what sources they rely on, and what quality standard their outputs must meet.  
>  
> This replaces the current `DNACompetency { code, name, description, level }` flat model with a structured professional standard that makes competency expectations auditable and founder-approved.  
>  
> A completed Competency Model is required before the Professional DNA is authored.  
>  
> It is not runtime content. It informs the DNA profile design.

## Proficiency Level Reference

| Level | Code | Meaning |
|---|---|---|
| **Foundational** | F | Understands the concept; can apply it under supervision or with clear guidance |
| **Practitioner** | P | Can apply reliably in standard situations; identifies edge cases |
| **Expert** | E | Handles complex and ambiguous situations; can explain reasoning; validates others' work |
| **Authority** | A | Defines the standard; resolves novel situations; production-ready without review |

*For NeedsOps AI Employees, the minimum acceptable level is Practitioner for any active capability. Foundational competencies may exist for awareness purposes only — they must not be used to produce professional outputs.*
