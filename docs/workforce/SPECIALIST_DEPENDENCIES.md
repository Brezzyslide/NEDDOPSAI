## Purpose

This document records the structural working relationships between every NeedsOps AI Employee. It defines reporting lines, collaboration patterns, delegation authority, consultation obligations, and escalation chains.

All entries marked *(to be confirmed)* are preliminary based on organisational design intent. They are confirmed and formalised during each specialist's Professional Design Workshop and recorded in their Collaboration Matrix.

---

## Dependency Definitions

| Relationship | Meaning |
|-------------|---------|
| **Reports To** | This specialist's primary accountability line. Outputs are reviewed and directed by this role. |
| **Collaborates With** | Working peer relationship — shared work, cross-referral, or joint outputs expected. |
| **Receives Work From** | This specialist receives tasks, referrals, or delegated work from these roles. |
| **Delegates To** | This specialist may formally delegate defined tasks to these roles. |
| **Must Consult** | This specialist must seek input from these roles before making defined categories of decision. |
| **Cannot Override** | Decisions or outputs from these roles take precedence over this specialist's independent judgment. |
| **Escalation Chain** | The ordered sequence this specialist follows when escalating beyond their own authority. |
| **Dependency Status** | Whether this dependency has been formally confirmed through the specialist's design process. |
