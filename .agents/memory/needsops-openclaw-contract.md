## Finding: OpenClaw did NOT cause the crash

The "Cannot read properties of undefined (reading 'id')" crash in the CoS → OM task was the `addMessage` → undefined SSE handler bug, fixed in the same session. OpenClaw was not involved because:

1. **CoS → OM uses a different path**: `dispatchWorkExecution` → `workExecutionPipelineService.executeWork` → AI gateway. This path never calls `engine.submitExecution()`. OpenClaw is only invoked via the explicit `POST /tasks/:id/submit` route (`executionService.submitTaskExecution`).

2. **No `.id` access on broker response**: `openClawExecutionEngine.submitExecution` reads `brokerResponse.status`, `brokerResponse.reason`, `brokerResponse.runtimeExecutionId`, `brokerResponse.estimatedStartAt`. No `.id` field.

3. **Update didn't change response contract**: Commits `841ec7e` and `caa0ae3` changed `gatewayAdapter.ts` (LiveGatewayAdapter modes) and added cross-platform adapters to the Electron app. `executions.ts` (the broker HTTP route), `OpenClawSubmissionResponse`, and `OpenClawWebhookEvent` were not touched.

4. **Webhook contract safe**: `BrokerWebhookEvent.eventId` is generated by the broker via `randomUUID()`, not echoed from OpenClaw binary — so even binary output changes don't affect the API server webhook contract.

## Defences added

**Boundary log** (in `submitExecution`, before response handling):
- Logs: `adapterName`, `executionId`, `correlationId`, `responseKeys`, `hasRuntimeExecutionId`, `hasStatus`, `hasRuntimeVersion`, `responseStatus`, `httpStatus`
- Does NOT log: `tenantId`, `organizationId`, `instruction`, credentials

**Contract validation** (`MALFORMED_BROKER_RESPONSE` guard):
- Non-object response → throws
- Status not in `accepted | queued | rejected` → throws
- `runtimeExecutionId` absent on accepted/queued → throws with field-name hint
- All typed `code: "MALFORMED_BROKER_RESPONSE"` so callers can distinguish from network errors

**`@workspace/openclaw` vitest alias**: Added to `artifacts/api-server/vitest.config.ts` so the engine can be tested in the API server's test suite without relative-path imports.

## Contract test file

`artifacts/api-server/src/__tests__/openclaw-contract.test.ts` — 27 tests covering:
- Valid accepted / queued / rejected responses
- MALFORMED_BROKER_RESPONSE guard for: missing field, unknown status, envelope wrapper, null, undefined
- Field-name assumption table (6 invalid ID variants, 9 invalid status values)
- Network errors: timeout marks session failed, ECONNREFUSED propagates
- Boundary log safety assertion
