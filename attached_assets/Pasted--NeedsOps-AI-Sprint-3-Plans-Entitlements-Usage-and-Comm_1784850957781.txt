# NeedsOps AI+

## Sprint 3: Plans, Entitlements, Usage and Commercial Foundation

Sprint 2 is approved and complete.

Proceed with Sprint 3 only.

Do not begin OpenClaw, browser execution, local computer access, external connectors, Stripe payments or live AI execution during this sprint.

The purpose of Sprint 3 is to build the commercial and entitlement foundation that controls what each organisation may access.

NeedsOps AI+ does not primarily sell individual AI agents.

Customers subscribe to:

1. an organisation plan
2. included user seats
3. monthly usage allowances
4. included workforce packs
5. included execution capabilities
6. optional premium add-ons
7. enterprise infrastructure options

The system must be ready to support live OpenClaw execution later, but no live runtime is introduced in this sprint.

---

# Core Architecture

Preserve the separation:

```text
Authentication
Who is the user?

Membership
Which organisation do they belong to?

Permissions
Can this user perform the action?

Entitlements
Does the organisation's plan include the capability?

Usage
Has the organisation exceeded its allowance?

Approval
Has a human approved this specific sensitive action?

Execution Policy
Is the action safe to perform through browser, local device or API?
```

Sprint 3 implements entitlements and usage.

# Seat Management

```typescript

```

Count:

* active memberships

* pending invitations
* suspended memberships
* revoked memberships

* keep existing members readable
* block new invitations
* show a clear warning
* do not automatically remove users

# Tests

Test:

## Entitlements

* plan grants included feature
* missing feature denied
* workforce pack grants specialist
* unavailable pack denies specialist
* browser execution entitlement resolves correctly
* local device entitlement resolves correctly
* API connector entitlement resolves correctly
* override grants feature
* explicit denial overrides plan grant
* expired override is ignored
* inactive subscription denies restricted capability
* trial grants temporary capability
* expired trial denies new restricted actions

## Usage

* usage below warning threshold allowed
* warning at 80%
* warning at 95%
* denial at hard limit
* unlimited usage allowed
* idempotent usage event not double-counted
* Tenant A usage isolated from Tenant B
* period boundary handled correctly

## Seats

* active memberships count
* pending invitations do not count
* suspended memberships do not count
* new invitation blocked at seat limit
* seat override increases limit
* over-limit downgrade preserves existing users

## Security

* organisation owner cannot create platform override
* Tenant A cannot view Tenant B subscription
* platform admin action is audited
* URL manipulation does not expose another tenant's commercial state

All tests must pass.
