This audit changes the priority quite a bit.

Before we do any more navigation cleanup, we need to fix access enforcement first. Hiding a menu item while the API still lets a member approve memory, resolve governance approvals, or open Blueprint Studio directly is cosmetic security. The backend has to become authoritative, then the UI should mirror it.

The good news is that the role model itself is not the problem. I would keep the six organisation roles. The problem is inconsistent enforcement and the old admin versus administrator naming drift.

I would also activate manager rather than remove it. It fills a useful gap between administrator and member. But I would narrowly define what it can approve.

My recommended boundary is:

Owner has full organisational authority. Administrator has full day-to-day operational and governance authority, but not the few owner-only matters such as organisation deletion or ultimate billing ownership. Manager can commission work and make normal operational work approvals, but should not govern the organisational knowledge base, Memory authority, blueprints, security, or high-risk governance settings. Member can ask, create and submit work, upload documents and consume outputs, but cannot approve governance decisions. Viewer is read-only operational visibility. Auditor is read-only governance/audit visibility.

That gives us an important approval distinction:

Manager can approve work. Administrator/Owner can approve authority.

So a manager could approve an ordinary onboarding plan or operational deliverable if your workflow allows it. But changing which policy is authoritative, approving organisational Memory, publishing a Blueprint, or resolving a high-risk governance exception should stay administrator/owner.

And nobody should be able to approve their own governed request where segregation of duties applies. Owner should not magically escape that simply because they are owner. If an organisation has only one owner/admin, then the product needs a clearly defined exceptional rule rather than silently pretending independent approval occurred.
