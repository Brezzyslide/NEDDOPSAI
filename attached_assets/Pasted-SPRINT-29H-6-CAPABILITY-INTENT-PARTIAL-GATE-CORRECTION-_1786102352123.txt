A — DEFINE ANALYSIS VS EXECUTION SEMANTICS
==================================================

Establish one canonical distinction:

PROFESSIONAL ANALYSIS

Examples:

- review policy
- identify compliance gaps
- assess risks
- recommend corrective actions
- create corrective action plan
- prepare improvement plan
- prioritise recommendations
- assign recommended responsible roles
- propose remediation
- draft implementation roadmap
- analyse incident process
- produce action plan

These produce intellectual/work-product output inside NeedsOps.

They do NOT constitute external execution.

EXECUTION

Examples:

- implement corrective action
- update the live policy
- change participant records
- send notification
- lodge report
- assign staff
- modify workflow/system
- email regulator
- save/write external file
- execute remediation
- perform connector side effect

These change external state.

The word "plan" must never by itself imply execution.
