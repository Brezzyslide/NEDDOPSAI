1. Database structure

Confirm whether NeedsOps now uses:

* one shared Platform Database
* one separate Operational Database for each organisation

Show the current database architecture and explain where each database is hosted.

Confirm whether separate organisation databases are:

* separate PostgreSQL databases on the same managed database server
