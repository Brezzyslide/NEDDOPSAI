Task #17 Objective

Implement the Knowledge Orchestration Engine.

This is significantly broader than traditional Retrieval-Augmented Generation (RAG).

The goal is to assemble the best possible context for every specialist by intelligently combining multiple governed knowledge sources while maintaining complete auditability.
