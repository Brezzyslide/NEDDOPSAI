Inspection Only — Chief of Staff Knowledge-First Behaviour & Specialist Availability

Do not change code yet.

Investigate why the Chief of Staff currently responds with messages like:

“Could you confirm if you have the latest version of the Medication Management Policy available for review? Once I have that, I will coordinate with the Operations Manager and Compliance & Quality Manager…”

The expected behaviour is:

1. Search the Organisation Library first.
2. Determine whether the required document exists, is current, approved, indexed, and retrievable.
3. Ask the user only when the required evidence is genuinely unavailable.
4. Check the workforce catalogue and runtime readiness before offering or assigning any specialist.
5. Only mention specialists that actually exist, are active, published, entitled, and operationally ready.

This is an inspection task only.

- getAvailableSpecialists

If not, identify the cleanest integration point.

The intended decision should be:

Request understood
→ identify required professional domains
→ query available and eligible specialists
→ select only specialists that are:
   - active
   - not archived
   - not coming soon
   - entitled
   - runtime ready
   - permitted for this task
→ offer or assign the valid team

If a useful specialist exists but is unavailable, the Chief of Staff may say:

“The Compliance & Quality Manager would normally support this work, but that specialist is not currently active. I can proceed with the Operations Manager only.”

It must not imply that an unavailable specialist will perform work.

Part 6 — Document question quality

Determine why the Chief of Staff asks:

“Do you have the latest version?”

instead of one of these:

Found:
“I found Medication Management Policy v4.2 in your approved Organisation Library and will use it.”

Missing:
“I searched your approved Organisation Library but could not locate a current Medication Management Policy.”

Not indexed:
“I found the policy, but it is still being processed and is not yet available for execution.”

Not approved:
“I found the policy, but it is awaiting approval before specialists can use it.”

The system should know the state and explain it precisely.

Identify what data is already available to support this behaviour and what is missing.
