Sprint 27.4 — Execution Inspector & Runtime Transparency

This is an observability sprint.

Objective

Build an Execution Inspector that exposes exactly what the Chief of Staff and each specialist are doing during execution, without exposing internal prompts or sensitive implementation details.

This is primarily a developer and platform-owner tool.

It should make debugging execution possible without reading logs.

Do not modify execution behaviour.

Do not change the work pipeline.

This sprint is inspection and observability only.
