Architecture Verification Sprint — Cloud vs Desktop Runtime Execution

Do NOT implement any changes.

This is an inspection and architecture verification exercise only.

Objective

Determine whether the current NeedsOps architecture already supports the following two execution scenarios.

Do not infer intent from documentation.

Trace the actual code paths from frontend → API → execution pipeline → gateway → connector → runtime.

────────────────────────────────────────

SCENARIO 1 — Cloud Knowledge Execution

User has uploaded organisational knowledge into NeedsOps.

Example:

Knowledge Hub
    Medication Policy
    Incident Policy
    Behaviour Support Policy

User asks:

"Review our Medication Management Policy through an operational lens."

Expected architecture:

Browser
↓
Chief of Staff
↓
Operations Manager
↓
Knowledge Resolution
↓
Organisation Knowledge Library
↓
Evidence Pack
↓
AI Gateway
↓
Completed Work

Determine:

• Is this execution path currently supported?
• Is it fully implemented?
• Which services are involved?
• Does the specialist receive the retrieved evidence?
• Is Completed Work generated without requiring OpenClaw?
• Which files implement this flow?

────────────────────────────────────────

SCENARIO 2 — Desktop Runtime Execution (No Knowledge Uploaded)

Assume:

The organisation has NOT uploaded any policies.

However:

• Desktop Connector installed
• OpenClaw Runtime running
• User has local files

Example:

Documents/
Medication Management Policy.docx

User asks:

"Review my Medication Management Policy."

Expected architecture:

Browser
↓
Chief of Staff
↓
Operations Manager
↓
Evidence Resolver detects missing organisation knowledge
↓
Desktop Connector
↓
OpenClaw Runtime
↓
Locate local file
↓
Read file
↓
Temporary Evidence Pack
↓
Operations Manager
↓
Completed Work

Determine:

• Is this execution path currently supported?
• Can the Chief of Staff request local evidence?
• Can OpenClaw currently locate local files?
• Can the runtime return document text?
• Can local document content become temporary execution evidence?
• Is any orchestration already implemented?
• If unsupported, identify exactly where execution stops.
