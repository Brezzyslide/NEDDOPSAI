You are implementing Sprint 27 only.

Goal

Complete the final wiring so the Chief of Staff behaves like a real executive assistant that can seamlessly execute professional work.

The desired experience is:

User chats with the Chief of Staff → CoS plans the work → asks for approval if required → dispatches specialists → work executes → Completed Work is created automatically → progress is visible in chat → user reviews and approves.

The user should never need to manually stitch together conversations, execution runs or Completed Work.
